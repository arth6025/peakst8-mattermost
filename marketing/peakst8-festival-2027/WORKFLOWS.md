### 1. Static post
```
PSF static post.
Headline: [WE'RE BACK FOR ROUND 2.]
Small line: [More to know.]
```

### 2. Carousel
```
PSF carousel, [5] slides, from this copy:
[paste copy]
Cover hook: [8 WAYS TO MOVE TOGETHER.]
Last slide: [30 Jan 2027. Tickets drop soon.]
```

### 3. Story
```
PSF story for [Midnight Run Rave].
Headline: [MIDNIGHT RUN RAVE.]
Details: [30 January 2027 · Bengaluru]
Sticker text: [SWIPE UP]
```

### 4. Reel cover
```
PSF reel cover. Title: [WHAT IS PEAKST8 FESTIVAL?]
Use a [running / football / basketball] photo from the image bank.
```

### 5. Highlight covers
```
PSF highlight covers for: [RUN, TALKS, FAQ, TICKETS]
```

### 6. Partner announcement
```
PSF partner post: [Ultrahuman], [Performance Partner].
Their logo is attached.
```

### 7. Speaker / athlete card
```
PSF speaker card: [Sania Mirza]. One line about them: [Tennis champion, 6 Grand Slam titles].
Photo attached.
```

### 8. Image to video
Make the post first (any template above), then:
```
Animate this PSF post into a [5]-second loop for Instagram.
Keep the text and logo exactly as they are; only the glass shapes should move.
```
For a Reel with captions: *"Make a [9]-second Reel from this PSF post, with captions."*
Claude shows the credit cost first and only runs when you say yes.

### 9. Copy first, then design
```
Write 10 hook options for the [Round 2 announcement] for peakst8 Festival.
```
Pick one, then: *"Make #[3] a PSF static post and a story."*

### 10. One post, every format
```
Make this a PSF static, story and reel cover:
Headline: [...]
```

### 11. A video like one you saw online
Use the Reference Video Kit: paste the link and get the same format back as a peakst8 video.
See [Reverse engineer any video](../reverse-engineer/README.md).

## Changing a post

Just say what to change, in plain words:
- "Bigger headline" / "put the headline on the left"
- "Use a blue background" / "use bg7"
- "Swap the photo for the neon sprinter"
- "Make a story version too"

Claude edits the post and shows it again.
