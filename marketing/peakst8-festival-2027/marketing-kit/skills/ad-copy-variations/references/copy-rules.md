# Copy rules

Adapted from marketing-skills `ad-creative` (hook system, awareness headlines, platform specs) and `copywriting`/`copy-editing` (AI tells). Verify platform limits before a large launch; they change.

## Character limits

| Platform | Field | Limit (safe) |
|---|---|---|
| Meta / Instagram | Primary text | 125 chars before "See more"; 2 200 max |
| | Headline | 27–40 chars |
| | Description | 27 chars |
| Google Search RSA | Headline | 30 chars, 15 slots, at least 8 distinct themes |
| | Description | 90 chars, 4 slots |
| Google PMax | Short headline 30 · long headline 90 · description 90 | |
| TikTok | Ad text | 100 chars; spoken hook ≤ 8 words |
| LinkedIn | Intro text | 150 chars before fold; headline 70 |
| Pinterest | Title 40 · description 500 (first 50 show) | |
| YouTube | Headline 15 · description 70 · long headline 90 | |

On-image text (Sloosh renders it): headline ≤ 6 words, sub ≤ 10, CTA ≤ 3, story cover ≤ 4; words ≤ 10 characters spell best.

## Hook moves

| Move | Shape | Watch |
|---|---|---|
| Curiosity gap | withhold the noun | pay it off inside the ad |
| Specific claim | falsifiable, concrete | needs proof on screen |
| Confession | "I was doing X wrong" | needs lived detail |
| Contrast | two states in the first beat | truthful frames |
| POV | hyper-specific situation | generic POV is invisible |
| Exact question | what they type into search | verbatim phrasing |
| Countdown / challenge | promise a payoff | payoff must exist |

Three-part rule for video: visual action, spoken line and caption each carry a different part of the idea. For statics: the headline must not caption the image.

Generation order: segment → motivation (verbatim) → format → hook. Fill a matrix across cells; ten hooks for ten cells beat thirty rewrites of one.

## Awareness treatments

Unaware: feeling, conversation. Problem-aware: pain + outcome, time-anchored friction. Solution-aware: state change, documented statistic. Product-aware: statistic, objection + proof. Stage is a hypothesis; if unknown, write for two stages and say so.

## Evidence

Language evidence (a complaint, a phrase) supports a pain angle. Claim evidence (a measured result with population and period) supports a number. Never upgrade one into the other. Keep a number's precision and qualifier; a rounded number is fine when it is true.

## Banned patterns (AI tells)

- "not X, it's Y" / "isn't X, it's Y" / "this isn't about X".
- "no X, no Y, no Z" triplets.
- Sentences that trail into extra comma clauses.
- Stacked rhetorical questions.
- "imagine", "unlock", "elevate", "effortless", "seamless", "game-changing", "revolutionary", "say goodbye to".
- Em dashes. Use a period or a colon.
- Invented testimonials, invented names, invented stats.

Fix by stating the thing: what it is, who it is for, what changes.

## Hypothesis format

"If [variant] beats [control] on [metric] by [threshold] for [segment], then [what we learn]." Hook rate (3-second views / impressions), hold rate (ThruPlay / 3-second views), CTR, CVR. One variable per comparison.
