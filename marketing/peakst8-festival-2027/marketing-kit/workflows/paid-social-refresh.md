# Workflow: paid social creative refresh

Two weeks of new creative from what the account already taught you.

```
creative-performance-retro (metrics table in) ─► ad-concepts (angles to test)
   ─► ad-copy-variations (hook matrix) ─► ad-hook-matrix (Space, 3 hooks on a grid)
   ─► static-ad-variants (winning hooks → 4:5 + 9:16, clean plate + text)
   ─► testimonial-ads / before-after-ad / comparison-ad (proof formats)
   ─► ugc-video-ad (2 creators × 1 hook) ─► captions-subtitles
   ─► reels-shorts-clip ─► creative-testing-plan (naming = idempotency keys)
```

One variable per comparison. Names flow from idempotency key → asset name → ad name, so the retro two weeks later reads straight off the ad account.
