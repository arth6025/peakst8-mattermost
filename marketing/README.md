# Marketing: workflows and skill files

Claude skills and step-by-step workflows for the peakst8 marketing team.

| Folder | What it does |
|---|---|
| [**peakst8-festival-2027/**](peakst8-festival-2027/README.md) | Turn copy into on-brand festival posts (static, carousel, story, reel cover, highlight covers), then into video. PSF27 brand kit + Marketing Kit (79 skills). **[Prompt templates →](peakst8-festival-2027/WORKFLOWS.md)** |
| [**reverse-engineer/**](reverse-engineer/README.md) | Paste any video from X, LinkedIn, YouTube or Instagram and get the same format back as a peakst8 MP4. |

Install everything for Claude Code in one go:

```
/plugin marketplace add arth6025/peakst8-mattermost
/plugin install psf27-social@peakst8
/plugin install marketing-kit@peakst8
```
